# Master-Chronik ALF

## ALF-007 – ALF-Pergamentrolle-001

**Ideator:** Sascha Hermeling  
**Masterprojekt:** Master-Chronik ALF  
**Technische Kennung:** ALF-007  
**Programm:** ALF-Pergamentrolle-001

Interaktive historische Lern- und Museumsstation zur Geschichte menschlicher Schriftsysteme.

### Leitgedanke

**MEHR BILDER ALS WORTE**

Der Besucher soll Geschichte sehen, entdecken und verstehen können, ohne lange Texte lesen zu müssen.

### Besucherprinzip

**Sehen → verstehen → entdecken**

Die Anwendung verbindet historische Schriftsysteme mit einer visuell erfahrbaren digitalen Pergamentrolle.

### Historische Schriftsysteme

Geplant sind unter anderem:

- Latein
- Binärdarstellung
- Sumerische Keilschrift
- Ägyptische Hieroglyphen
- Altgriechisch
- Runen
- Phönizisch
- Ge’ez
- weitere historisch belegte Schriftsysteme

Es werden keine erfundenen historischen Zeichen verwendet.

### Erste dokumentierte visuelle Entwicklungsstufe

**21.09.2026 – 20:18:51**

Dieser Zeitpunkt bezeichnet den ersten dokumentierten visuellen Meilenstein von ALF-Pergamentrolle-001.

### Langfristige Vision

Aus ALF-Pergamentrolle-001 soll ein interaktives Museumsterminal entstehen.

Geplante Funktionen:

- horizontales Blättern
- Zoom
- interaktive historische Zeichen
- kurze verständliche Informationen
- Vorlesefunktion
- Bilder und historische Fundstücke
- zeitliche und geografische Einordnung
- Touchscreen-Bedienung
- Mehrsprachigkeit

### Projektgedanke

Die Geschichte der menschlichen Schrift soll nicht nur gelesen werden.

**Sie soll entdeckt werden.**
